## 📌 Overview

**Vadapalani Shooting House** is a production-grade web application built for Chennai's premier film shooting property situated at **4/5 Varghese Avenue, Ashok Nagar, Vadapalani, Chennai 600083**.

Engineered with **React 19**, **TanStack Router / Start SSR**, **Tailwind CSS v4**, and **Vite**, the application delivers sub-second page loads, mobile PWA capabilities for on-the-go line producers, comprehensive JSON-LD structured schemas (`LocalBusiness` and `FAQPage`), and instant 1-tap WhatsApp recce coordination.

---

## ✨ Key Features

- **⚡ High-Performance Architecture**:
  - Server-Side Rendering (SSR) via TanStack Start and Nitro Vercel edge preset.
  - Interactive facades for Google Maps and YouTube video tour to eliminate third-party script bloat and maintain green Core Web Vitals.
  - Responsive image loading with high-priority hero preloading.

- **📱 Progressive Web App (PWA)**:
  - Full Web App Manifest (`manifest.json`) and iOS touch icon (`apple-touch-icon.png`).
  - Allows directors and production managers to tap "Add to Home Screen" on iPhone or Android for direct 1-tap booking access.

- **🔍 Local SEO Dominance**:
  - Pre-rendered JSON-LD schema matching Google Rich Snippet guidelines (`LocalBusiness` with exact geo-coordinates `13.0336, 80.2114`).
  - Specialized Film Production FAQ schema covering night shoots, generator van parking, and complimentary recce walkthroughs.
  - Dynamic XML Sitemap (`/sitemap.xml`) discovered and indexed by Google Search Console.
  - Permissive `robots.txt` optimized for Googlebot, Bingbot, and Applebot.

- **🎬 Production-First Media Gallery**:
  - Interactive full-screen image lightbox for location recce exploration.
  - Reference stills from verified feature films shot on site.
  - Video walkthrough embedded with click-to-play performance facade.

- **🌐 Internationalization (i18n)**:
  - English and Tamil language switcher for native communication with local directors, line producers, and coordinators.

- **📊 Vercel Edge Telemetry**:
  - Integrated with `@vercel/speed-insights` for real-time Core Web Vitals tracking.
  - Integrated with `@vercel/analytics` for privacy-first visitor and recce click attribution.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: `v20.x` or higher
- **Package Manager**: `npm` (or `pnpm` / `bun`)

### 1. Clone the Repository

```bash
git clone https://github.com/Mukilan-s18/Movie-Shooting-Website.git
cd "Movie-Shooting-Website"
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production

```bash
# Standard Vite build
npm run build

# Vercel Edge Serverless build
npm run build:vercel
```

### 5. Run Linting and Code Quality Checks

```bash
npm run lint
```
